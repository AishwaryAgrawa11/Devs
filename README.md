## 📝 Daily Rules

### 1️⃣ One Problem Every Day

Everyone should try to solve the **same Problem of the Day**.

### 2️⃣ Use Your Own Folder

Put your solution only inside your personal folder.

### 3️⃣ Don't Copy Solutions

Try solving the problem yourself before looking at someone else's solution.

Discussion and helping each other is encouraged. However, everyone should submit their **own implementation**.

### 4️⃣ Different Languages Are Allowed

You can use:

- C++
- Java
- Python
- JavaScript
- C
- etc.

### 5️⃣ Add Complexity

Mention the time and space complexity whenever possible.

Example:

```text
Time Complexity: O(n)
Space Complexity: O(1)
```

### 6️⃣ Commit Every Solution

Use a meaningful commit message.

Example:

```text
Day 01 - Solved Two Sum
```

## 🤝 Contribution

### First Time Setup

Clone the repository:

```bash
git clone <repository-url>
```

Enter the repository:

```bash
cd Problem-of-the-Day
```

### For Each Problem

1. Go to your personal folder.
2. Add your solution.
3. Commit your changes.
4. Push to GitHub.
5. Update the progress table.

Example:

```bash
git add .
git commit -m "Day 01 - Solved Two Sum"
git push
```
